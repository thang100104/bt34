# BT34 - Căn giữa phần tử bằng Flexbox

Bài thực hành sử dụng Flexbox để căn giữa một thẻ thông báo theo cả chiều ngang và chiều dọc.

## Ba dòng CSS cốt lõi

```css
display: flex;
justify-content: center;
align-items: center;
```

## Cách chạy

Mở file `index.html` bằng trình duyệt hoặc Live Server trong VS Code.
